-- CRUD PARA LA VACANTE EN GRIVER HECHO EN C# CON LA CONEXION A UNA BD EN SQL--

Este proyecto consiste en una aplicación de escritorio realizada con **C# y Windows Forms**, que implementa un **CRUD (Crear, Leer, Actualizar, Eliminar)** conectado a una base de datos en **SQL Server**. También incluye la generación de reportes utilizando **Crystal Reports**.

-  CRUD completo sobre una tabla de empleados.
-  Conexión con **SQL Server** usando `SqlConnection`.
-  Reporte generado con **Crystal Reports** que muestra los registros almacenados.
-  Botón en la interfaz para visualizar el reporte.


 Base de Datos

La base de datos utilizada en este proyecto se encuentra en la carpeta `BD_SQL_SERVER`.

  Cómo restaurar la base de datos:

1. Abrir **SQL Server Management Studio**.
2. Conectarse a su servidor local.
3. Abrir y ejecutar el script `base_datos.sql`.
4. Verificar que la base se creó correctamente.

 **Importante:** Asegurarse de que el nombre de la base de datos en el script coincida con el que usa en la conexión dentro del proyecto
